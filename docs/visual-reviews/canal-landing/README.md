# Canal Landing · v0.8.0

`landing.png`는 SquareScene의 실제 에셋을 임시 검토 Camera로 렌더한 이미지다. Camera와 렌더용 객체는 저장하지 않았다.

- 장식용 선착장 1개, 나룻배 1척. 배는 정적으로 정박해 있다.
- Scene 기존 serialized object 삭제 0. 기존 객체 변경은 Willow Court의 신규 자식 연결 1개뿐이다. Unity 저장 과정의 객체 재정렬로 text diff가 커 보일 수 있다.
- Scene Missing Script 0. 신규 Mesh·Material 누락 0. 신규 Collider 0.
- Mac / Windows v0.8.0 빌드 성공, 오류 0. 기존 폰트 importer 및 지형 Collider 사전 베이크 경고가 있다.
- 두 ZIP CRC 검증 성공. 배포 금지 백업 폴더 제외.
- 온라인 로그인·멀티플레이 흐름과 Windows 실기기 실행은 이번 작업에서 검증하지 않았다.
